## Kurulum

1. İndirdiğiniz `SimpleClicker.exe`'yi çalıştırın
2. Sonrakine basın, lisansı kabul edin sonraki ve kurun
3. Masaüstü kısayolu otomatik olarak oluşturulacaktır
